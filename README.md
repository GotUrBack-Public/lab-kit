**lab-kit** is an open research lab for studying security concepts, malware behavior, reverse engineering, and defensive techniques.

The material in this repository is intended for research, education, experimentation in isolated environments, and as a foundation for building your own tools. The project is open source under the MIT License; see [LICENSE](LICENSE) for the terms.
